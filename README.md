# Флора — статический сайт о цветах 🌸

Небольшой одностраничный сайт студии флористики. Чистый HTML + CSS + JavaScript — без сборки, фреймворков и зависимостей. Готов к публикации на **GitHub Pages**.

## Структура проекта

```
flower-site/
├── index.html          # Единственная страница (все секции)
├── .nojekyll           # Отключает обработку Jekyll на GitHub Pages
├── css/
│   └── style.css       # Стили + адаптив под мобильные
├── js/
│   └── script.js       # Меню, анимации, кнопка «наверх»
├── images/             # 8 изображений (hero, каталог, о нас)
└── README.md
```

⚠️ **Важно:** `index.html` должен лежать в **корне репозитория**, рядом с ним — папки `css`, `js`, `images`. Если в репозитории оказалась вложенная папка `flower-site/flower-site/` — сайт не откроется.

## Локальный просмотр

Просто откройте `index.html` в браузере — установка ничего не требует, сайт работает и без сервера.

Либо запустите мини-сервер (как на GitHub Pages):

```bash
python -m http.server 8000
# затем откройте http://localhost:8000
```

## Публикация на GitHub Pages

### Вариант 1 — через веб-интерфейс GitHub

1. Создайте новый репозиторий на https://github.com/new (например, `flower-site`).
2. Нажмите **Add file → Upload files**.
3. Перетащите **содержимое** папки `flower-site`: файлы `index.html`, `.nojekyll`, `README.md` и папки `css`, `js`, `images` **вместе**.
   > ⚠️ Не загружайте ZIP-архив как файл и не пропускайте папки — иначе стили и картинки не найдутся.
4. Дождитесь загрузки и нажмите **Commit changes**.
5. Откройте **Settings → Pages** (слева).
6. В блоке «Build and deployment» выберите:
   - **Source**: `Deploy from a branch`
   - **Branch**: `main`, папка: `/ (root)`
7. Нажмите **Save** и подождите 1–2 минуты.
8. Сайт откроется по адресу: `https://ВАШ_ЛОГИН.github.io/flower-site/`

### Вариант 2 — через Git из командной строки

```bash
cd flower-site

git init
git add .
git commit -m "Первый коммит: сайт о цветах"

# Создайте репозиторий flower-site на GitHub, затем:
git branch -M main
git remote add origin https://github.com/ВАШ_ЛОГИН/flower-site.git
git push -u origin main
```

После этого включите Pages: **Settings → Pages → Branch: main / root → Save**.

## Если что-то не отображается

| Симптом | Причина | Решение |
|---|---|---|
| 404 «There isn't a GitHub Pages site here» | Pages не включён или index.html не в корне репозитория | Settings → Pages → Branch `main` / `(root)`; проверьте, что index.html в корне |
| Сайт открыт, но без стилей и картинок | Загружен только index.html, без папок css/js/images | Загрузите ВСЁ содержимое: папки css, js, images должны лежать рядом с index.html |
| В репозитории папка `flower-site/flower-site/` | Загрузили папку целиком вместо содержимого | Перенесите файлы из вложенной папки в корень репозитория |
| Секции пустые, контент невидим | Не загрузился js/script.js (в версии сайта до 24.10 контент скрывался без JS) | Обновите сайт — теперь весь контент виден даже без JavaScript |
| Не открывается после коммита | Pages ещё строится | Подождите 1–2 минуты и обновите страницу (Ctrl+F5) |

Контрольная проверка репозитория: в корне должны лежать `index.html`, `.nojekyll`, папки `css/`, `js/`, `images/`.

## Как обновлять сайт

- **Тексты и цены** — редактируются прямо в `index.html`.
- **Цвета и шрифты** — переменные в начале `css/style.css` (блок `:root`):
  `--accent` — розовый акцент, `--ink` — зелёный текст, `--bg` — кремовый фон.
- **Фото** — замените файлы в папке `images/`, сохранив имена.

## Встроенные шрифты

Сайт использует Google Fonts (Playfair Display + Manrope) через CDN.
Если нужен полный оффлайн — скачайте файлы шрифтов и подключите их локально.

## Форма заявки

Сайт статический, поэтому форма не отправляет данные на сервер. Демо-обработчик
находится в `js/script.js`. Для реального приёма заявок без бэкенда подключите
бесплатный сервис [Formspree](https://formspree.io):

```js
// в js/script.js замените демо-обработчик на:
form.action = 'https://formspree.io/f/ВАШ_ID';
form.method = 'POST';
```
