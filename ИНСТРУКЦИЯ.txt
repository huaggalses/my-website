ЧТО ЭТО ТАКОЕ
-------------
Это готовый статический сайт о цветах.
Внутри архива: index.html, папки css, js, images.
Ничего устанавливать не нужно.


ШАГ 1. Распакуйте архив
-----------------------
Кликните по архиву правой кнопкой → «Извлечь всё».
После распаковки вы увидите папку с файлами:

  index.html      ← главная страница
  .nojekyll       ← служебный файл для GitHub
  css\            ← стили
  js\             ← скрипты
  images\         ← фото цветов
  README.md       ← подробная справка


ШАГ 2. Посмотрите сайт (необязательно)
--------------------------------------
Просто дважды кликните по index.html —
сайт откроется в вашем браузере.


ШАГ 3. Загрузите на GitHub
--------------------------
1. Зайдите на github.com и войдите в аккаунт
2. Нажмите «+» справа вверху → «New repository»
3. Имя: flower-site   Видимость: Public
4. Нажмите «Create repository»
5. На открывшейся странице нажмите ссылку
   «uploading an existing file»
6. Перетащите В СОКНО: index.html, .nojekyll,
   README.md и папки css, js, images ВМЕСТЕ

   ВАЖНО: перетаскивайте всё содержимое сразу,
   а не сам ZIP и не папку целиком!

7. Нажмите зелёную кнопку «Commit changes»


ШАГ 4. Включите публикацию
--------------------------
1. В репозитории: Settings (шестерёнка) → Pages
2. Branch: выберите main, папка / (root)
3. Нажмите «Save»
4. Подождите 1–2 минуты


ШАГ 5. Готово!
--------------
Сайт откроется по адресу:

  https://ВАШ_ЛОГИН.github.io/flower-site/

Поделитесь этой ссылкой с кем угодно.


ЕСЛИ ЧТО-ТО НЕ ТАК
------------------
• «404 There isn't a GitHub Pages site here»
  → проверьте Шаг 4: Pages включён? main / (root)?

• Сайт открылся, но без стилей и картинок
  → на GitHub не загружены папки css/js/images.
    Загрузите их рядом с index.html.

• В репозитории появилась папка flower-site
  внутри flower-site → перенесите файлы
  из вложенной папки в корень.

Подробная справка — в файле README.md.
